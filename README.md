# React Dev Week 1 Activity

## TypeScript and Webpack Book Application

This project is a simple book application converted from JavaScript to TypeScript. It demonstrates TypeScript classes, type annotations, interfaces, and Webpack bundling.

## Technologies

* HTML
* TypeScript
* Node.js
* npm
* Webpack
* ts-loader

## Project Structure

```text
react-dev-week1-Activity/
├── my-project/
│   ├── index.html
│   ├── src/
│   │   └── main.ts
│   ├── dist/         # generated by build
│   └── webpack.config.js
├── package.json
├── package-lock.json
├── tsconfig.json
├── .gitignore
└── README.md
```

## Features

* `Book` class with typed properties and constructor.
* Type annotations for variables and functions.
* `Review` interface for book reviews.
* `addReview()` function for storing reviews.
* Webpack configuration for bundling TypeScript.
* TypeScript compilation using `ts-loader`.

## Installation

Install the project dependencies:

```bash
npm install
```

## Quick start

Install dependencies and build from the repository root:

```bash
npm install
npm run build
```

The build outputs the bundle to `my-project/dist/bundle.js` (see `my-project/webpack.config.js`).

## Run / Preview

Open `my-project/index.html` in a browser, or serve the folder with a static server for correct MIME handling:

```bash
npx serve my-project
```

The application should display the sample books on the page.

## TypeScript Check

To check for TypeScript errors without generating files:

```bash
npx tsc --noEmit
```
